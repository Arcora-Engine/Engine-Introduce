# format

[返回总览](../README.md)

`format` 是 Haxe 文件格式处理库，提供图像、音频、归档、文档、字节码及其他二进制数据的读取、写入和转换能力。各格式提供的能力不同，具体范围如下。

## 格式支持总览

| 分类 | 支持格式与能力 |
| --- | --- |
| 图像 | PNG、BMP、GIF、TGA 的读取与写入；ICO 读取；JPEG 写入及 HashLink 原生解码。 |
| 音频与媒体容器 | WAV、MP3、FLV 的读取与写入。 |
| 压缩与归档 | ZIP、TAR 读写；GZ、TGZ 读取；LZ4 读取与解压。 |
| 文档与可执行文件 | PDF 对象读取与部分旧版加密处理；32 位和 64 位 ELF 读取。 |
| 字节码与调试映射 | HashLink HLB、Neko 字节码读取；Neko 模拟执行；Source Map 查询。 |
| 数据交换 | AMF、AMF3 数据读写。 |
| Flash 与图形程序 | SWF、ActionScript 1、ABC 字节码处理；AGAL 写入与检查；Pixel Bender（PBJ）读写。 |
| 粒子与底层工具 | PEX 粒子配置读取；压缩、校验、哈希、位流和二进制数据处理。 |

## 特色功能

- **检查素材与底层文件结构**：可以提取 GIF 动画帧及画面、检查 MP3 帧头和采样数、读取 ELF 文件结构，适合制作资源导入、检查与转换工具。
- **处理旧版运行时与内容格式**：提供 HashLink、Neko、SWF、ActionScript、AGAL、Pixel Bender 和 PEX 等格式处理，适合读取或迁移已有内容；HashLink 字节码读取范围为 HLB 2 至 5。
- **结合 Haxe 格式处理与原生图像能力**：文件结构和多种像素处理由 Haxe 模块提供；HashLink 可在具备匹配原生模块时使用 JPEG、PNG 与 DXT 解码。各格式的读写能力见下文。

## 图像格式

PNG 支持读取图像头和调色板、提取灰度或 32 位像素，也支持从灰度、索引、RGB、ARGB 和 BGRA 数据生成图像。BMP 和 TGA 提供图像读写与像素处理；BMP 可以将受支持的调色板或真彩数据提取为 ARGB/BGRA，TGA 支持提取 32 位、Alpha 和灰度数据。

GIF 支持读写、帧数和循环次数读取，以及单帧或合成后的 RGBA/BGRA 画面提取。ICO 支持读取图标并提取位图数据。JPEG 提供写入功能；HashLink 目标在具备匹配原生模块时还可解码 JPEG 和 PNG、缩放图像，并可在 HashLink 1.10 及以上使用 DXT 纹理解码。

## 音频、媒体容器与归档

WAV 支持 PCM 与 IEEE 浮点音频数据及格式信息读写，也能读取位于音频数据块之后的 cue 点；MP3 支持帧头、帧数据、码率、采样率、样本统计和原始 ID3v2 标签处理；FLV 支持音频、视频与元数据标签读写，以及视频关键帧判断。这些功能处理文件结构和数据，实际播放还需要相应的解码器与音视频运行时。

ZIP 和 TAR 支持归档读取与写入，ZIP 支持单独压缩和解压条目。GZ、TGZ 和 LZ4 提供各自的读取或解压能力。LZ4 读取支持压缩块和未压缩块，但不支持预设字典，当前读取过程不校验帧头、块和内容校验值；需要完整性保证时应另行验证数据。底层工具还包括 Deflate/Inflate、Huffman、CRC32、Adler32、MD5、位流及缓冲处理，ArcFour 可用于兼容旧格式。

## 文档、字节码与映射

PDF 支持对象读取、字段提取和 FlateDecode 过滤，并能解密部分旧版 Standard 加密数据，范围为加密版本 2、修订 3 或 4。ELF 支持读取 32 位和 64 位文件头、section 头及相关原始字节。

HashLink 字节码读取功能可以处理类型、常量、全局数据、函数与调试信息，并提供类型中指针判断和名称哈希工具，覆盖 HLB 2 至 5；HLB6 需要使用支持该版本的其他工具。Neko 功能包括字节码读取、Haxe 模拟执行和部分模板处理；默认加载方式不加载原生 primitive。

Source Map 支持根据生成文件中的行列查找原始位置，也可以遍历映射。AMF 和 AMF3 支持常见数据类型的读写，包括对象、数组、字符串、数值；AMF3 还覆盖日期、向量、XML、字节数组和映射。

## 动画、图形程序与粒子格式

SWF 支持标签及结构读写，ActionScript 1 和 ABC 支持指令数据处理；ABC 还支持常量池构建。AGAL 提供图形指令写入、寄存器属性与文本检查，PBJ 支持 Pixel Bender 指令数据读写及检查。

PEX 支持解析 XML 粒子发射器配置，包括纹理、生命周期、速度、重力、尺寸、旋转、颜色和混合参数。
