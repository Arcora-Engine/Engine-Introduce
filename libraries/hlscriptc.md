# hlscriptc

[返回总览](../README.md)

hlscriptc 是 Arcora 的 Haxe 脚本编译与运行工具链。它把脚本编译为 HashLink HLB6 字节码，让游戏和工具在运行时加载、执行和更新脚本，也支持接入其他宿主程序。

## 功能总览

| 功能 | 支持的能力 |
| --- | --- |
| 脚本编译 | 支持源码文件、字符串和字节数据，提供 Direct 与 NativeHaxe 两种编译前端。 |
| 宿主执行 | 支持在现有 HashLink 运行时中执行脚本，也支持通过执行驱动接入其他宿主。 |
| 引擎交互 | 支持脚本访问经声明的宿主能力，接收 Arcora 生命周期、场景和输入事件。 |
| 驻留与热更新 | 支持复用已加载模块、自动或手动更新，以及符合条件时的旧版本延迟回收。 |
| 安全控制 | 支持访问范围限制、字节码加密和摘要校验；不可信脚本可接入进程隔离执行。 |
| 工具链 | 支持命令行、原生宿主接入、增量缓存、依赖检查和编译结果复用。 |

## 特色功能

- **运行中编译 Haxe 脚本**：Direct 在宿主进程内生成 HLB6 字节码，适合游戏行为和工具扩展；需要 HXML、haxelib 和元数据等受支持前端功能的项目还可选择 NativeHaxe。两种前端均需匹配的编译与运行组件。
- **驻留执行与热更新**：脚本模块和实例可以跨回调保留；显式绑定路径在新版本准备失败时保留旧绑定和实例。旧版本代码可在符合条件时延迟回收，供仍存活的脚本对象继续使用。
- **按可信程度选择执行环境**：可信脚本可在匹配的 HashLink 宿主中运行；不可信脚本需要 Direct 前端、允许范围以及独立进程隔离。项目需要接入隔离执行实现，并由宿主和操作系统强制资源限制。

## 两种脚本编译前端

**Direct** 是默认前端，在进程内完成解析、类型检查和 HLB6 字节码生成；普通编译不需要启动外部 Haxe 或 HashLink 进程。它需要配套的原生编译器和运行时桥接组件。

**NativeHaxe** 使用经过适配的 Haxe 4.3.7 前端与 HLB6 打包工具。它支持允许范围内的 HXML、haxelib、元数据与编译选项，适合需要利用 Haxe 编译工具链的项目；需要部署匹配的编译器与打包组件。

两种前端面向 Haxe 4.3.7 的非宏语言功能，覆盖类与接口、抽象类型、泛型、结构类型、枚举与模式匹配、闭包和反射等语言能力，并可在受控范围内使用 JSON、数学、字符串与文件等标准库功能。

部分 Haxe 5 预览语法已定向移植，包括二进制整数字面量、模式匹配中的布尔条件、私有属性存取器和可空函数的安全绑定；这不代表完整 Haxe 5 支持。宏声明、宏表达式、构建宏和编译期命令不在支持范围内。

编译产物可保存为文件或保存在内存中；编译缓存根据源码、依赖、工具链与有效配置判断是否可复用，并支持检查、清理及从有效缓存恢复输出。外部编译或打包过程支持执行时限、输出大小限制和取消。

## 引擎交互与运行时执行

Arcora 可以将场景加载、初始化、逻辑更新、渲染更新、窗口尺寸变化、资源加载、图形上下文丢失、结束和输入事件分发给脚本，项目也可以定义自己的事件。脚本支持静态和实例方法，宿主可与脚本交换基本值、字符串、数组及约定的数据对象。

进程内桥接可以按声明使用 Arcora 对象、事件、宿主函数和构造能力；原生资源可以通过受类型、所有者、代际及有效期约束的不透明句柄交互。其他宿主也可以通过 C/C++ 原生能力接入编译与执行流程。

## 驻留执行与热更新

驻留执行可以保留已加载的脚本模块和实例，适合需要反复执行的游戏行为。工具链提供检查源码与依赖变化的自动更新路径，也提供由宿主决定更新时机的绑定路径；后者可以在候选版本通过编译、加载和函数签名兼容检查后发布，准备失败时保留原有绑定和实例。成功发布新版本后，绑定路径在首次调用时构造新实例。

更新后，旧代码可能仍被已有对象、闭包或类型引用。宿主需要在首次进程内加载脚本前配置代数与内存预算，并在维护阶段主动执行回收；垃圾回收确认旧版本不可达后，才能释放对应模块和 JIT 资源。该机制当前要求 64 位 JIT、Mark-Sweep GC，以及匹配的 HashLink 运行时与适配组件。不同调用路径对检查、实例保持和加密的支持范围有所区别。

## 安全与平台

脚本可见范围可以通过允许或限制宿主声明及成员来控制。字节码加载支持 AES-256 的 CBC、CFB、CTR、ECB、OFB 和 PCBC 等模式，也支持 SHA-256 摘要校验；这些加密模式本身不提供软件包真实性保证。显式绑定的更新路径目前不支持字节码加密。

不可信脚本执行要求使用 Direct 前端、显式允许范围和受限制的独立进程执行环境，并设置内存、执行时间和字节码大小上限。项目需要接入能够强制执行这些限制的宿主驱动；文件、网络和子进程权限还需要由宿主与操作系统限制。

Arcora 集成需要匹配的 Haxe 4.3.7、HashLink 1.16、编译器、原生适配器和脚本依赖。Windows、Linux、Android 等目标各需对应构建组件；原生发布是否支持动态脚本和热更新，还取决于宿主、执行方式与平台配置。
