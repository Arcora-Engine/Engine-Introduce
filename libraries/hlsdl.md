# hlsdl 窗口、输入与跨平台图形

[返回总览](../README.md)

`hlsdl` 为 Haxe、HashLink 和 Arcora 提供基于 SDL3 的窗口、输入和图形平台能力，可用于跨平台原生应用。

## 功能总览

| 功能 | 支持范围 |
| --- | --- |
| 窗口与显示 | 窗口创建、显示器、多窗口、缩放、全屏、VSync 和光标。 |
| 用户输入 | 键盘、文字、鼠标、触摸、游戏控制器、摇杆和震动反馈。 |
| 系统交互 | 剪贴板、系统消息框、拖放、应用数据目录与包内资源访问。 |
| 图形接口 | OpenGL、OpenGL ES、Vulkan 和部分 Metal 宿主接入。 |
| 显示与计时 | 单调时钟、输入事件时间、帧节奏、呈现反馈与性能统计。 |
| 多媒体互操作 | Android OpenGL ES 与 MediaCodec 解码表面的纹理互操作。 |

## 特色功能

- **跨平台窗口与图形接入**：基于 SDL3 提供窗口、输入和显示服务，Vulkan 可用于 Arcora 的现代原生渲染，OpenGL / OpenGL ES 提供兼容及移动路径。
- **输入与音视频时间关联**：输入事件包含原始时间、主机单调时钟时间、时钟域和误差估计，可供节奏游戏或输入延迟分析使用。精确判定需要可靠的主机单调时钟域，其他时钟域需要按估计或未知处理。
- **Android 视频纹理互操作**：可将 MediaCodec 解码表面交给 OpenGL ES，通过 GPU 转为普通纹理；该路径需要 OpenGL ES 3 与相应 external-OES 扩展。
- **呈现与帧节奏诊断**：支持按截止时间安排帧节奏，并记录等待、错过截止时间和帧间隔；Vulkan 的实际显示反馈取决于系统和设备。

## 图形接口与平台定位

| 图形接口 | 支持范围 |
| --- | --- |
| **Vulkan** | 提供实例、设备、交换链、图形与计算命令、同步和现代 GPU 功能接入。 |
| **OpenGL / OpenGL ES** | 提供窗口上下文、着色器、纹理、缓冲区和绘制功能，适用于桌面和移动兼容路径。 |
| **Metal** | 提供窗口视图与 Objective-C 宿主适配源码；Apple 目标仍需构建模块并完成宿主接入。 |

Vulkan 是 Arcora 的主要现代原生图形路径之一，OpenGL / OpenGL ES 提供兼容与平台路径。实际能力取决于操作系统、图形驱动、设备和启用的扩展；Metal 宿主源码需要配合 Apple 目标的进一步接入。

## 窗口、显示和系统交互

窗口能力包括标题、图标、尺寸、位置、透明度、显示模式、窗口与全屏切换、显示缩放和垂直同步。应用可使用系统或自定义光标、捕获鼠标、读取相对移动，并设置文字输入区域。

系统交互包括剪贴板、系统消息框、文件拖放和应用数据目录；CPU 图像表面可使用 8、16、24 或 32 位像素，为窗口图标和自定义光标提供图像。包内资源支持只读和定位读取：Android 可访问 APK 资源，Apple 平台可访问应用包中的 SDL 资源目录。

## 键盘、鼠标、触摸和手柄

键盘输入覆盖按键、重复输入和文本，并区分按键含义与物理位置；鼠标支持位置、相对移动、按键与滚轮。触摸支持多触点及触点标识。

游戏控制器和摇杆支持设备连接、名称、标识、按键及摇杆轴，部分设备还支持方向帽和震动反馈。窗口事件涵盖显示、移动、尺寸、屏幕缩放、焦点、关闭和文件拖放。

输入事件提供 SDL 原始时间、映射到主机单调时钟的时间、时钟域与误差估计，便于同音频或模拟时间进行关联。

## OpenGL 与 Vulkan 图形能力

OpenGL / OpenGL ES 覆盖着色器编译与链接、顶点数组、缓冲区、2D/3D 纹理、帧缓冲、采样和绘制；实例绘制、查询、图像绑定与计算着色器取决于上下文版本和扩展。支持多窗口图形上下文与窗口尺寸变化。

Vulkan 能力覆盖显式内存分配、缓冲区与图像、描述符、渲染管线、主与次级命令缓冲、图形和计算队列、复制及资源屏障，并支持信号量、fence、时间戳与呈现时序。

在设备支持时还可使用稀疏图像、加速结构、光线追踪管线、Mesh Shader 和 HDR 元数据。设备能力信息包括已启用的功能、队列与限制。

Android OpenGL ES 可与 MediaCodec 视频解码表面互操作，并通过 GPU 将外部视频纹理转换为普通 RGBA 纹理；该路径需要 OpenGL ES 3 上下文及 external-OES 和 ESSL 3 外部纹理扩展。与 [arcora-renderfx](arcora-renderfx.md) 等扩展配合时，可在满足条件的设备上共享所需图形资源。

## 帧节奏与诊断

帧节奏控制可按截止时间安排下一帧，并记录错过截止时间、等待与自旋、帧间隔分位数和延迟。Vulkan 可查询设备提供的呈现时间；实际显示反馈取决于系统和设备是否提供。

可选原生调用计时可以统计命令录制、上传、同步、提交和呈现阶段的调用次数与 CPU 耗时。计时可能包含驱动等待和嵌套调用，应与 GPU 时间区分。

## 平台与运行条件

| 平台 | 运行范围 |
| --- | --- |
| Windows x64、Linux x64 | 提供预编译运行组件，支持 OpenGL 和 Vulkan 路径。 |
| Android arm64 | 通过提前编译的应用及宿主接入 OpenGL ES 或 Vulkan，目标配置要求 API 24 及以上。 |
| Linux arm64 | 需要为目标宿主构建或提供匹配的运行组件。 |
| macOS、iOS | 提供宿主构建入口；Metal 路径还需要完成目标平台接入。 |

运行时需要与构建配置匹配的 SDL3、HashLink 和原生图形组件。Vulkan 还依赖系统加载器和驱动。
