# HashLink

[返回总览](../README.md)

HashLink 是 Arcora 使用的 Haxe 运行时，负责执行程序、管理托管内存，并连接图形、音频、网络和平台原生模块。配套版本同时提供字节码 JIT、LLVM AOT 运行支持、垃圾回收、原生互操作和诊断能力。

## 功能总览

| 功能 | 支持的能力 |
| --- | --- |
| 程序执行 | 支持 HLB6 字节码加载和 JIT 编译，配合 LLVM AOT 运行提前编译的原生程序。 |
| 内存管理 | 提供 Mark-Sweep 与 ZGC64 两种垃圾回收模式、内存配置和运行统计。 |
| 原生互操作 | 通过 HashLink ABI 连接 C/C++ 模块，并支持原生资源、引用与回调管理。 |
| 动态脚本 | 提供脚本上下文执行基础，可与 hlscriptc 的模块驻留和热更新配合。 |
| 系统能力 | 提供线程、文件、网络、TLS、数据库、音视频和平台组件的运行基础。 |
| 性能诊断 | 在匹配的构建中提供线程、分配、GC、异常和原生调用等分析数据。 |

## 特色功能

- **统一的字节码格式衔接开发与原生发布**：配套 HLB6 字节码格式用于 HashLink JIT，也可通过 Beap 和 LLVM AOT 生成目标平台程序。构建产物需要匹配运行时、目标平台及所选内存布局。
- **可选择的托管内存机制**：运行时提供 Mark-Sweep 与 ZGC64；ZGC64 的并发处理和对象搬迁需要匹配的 64 位运行时及原生模块。GC 模式在启动时选择，部分 AOT 产物固定收集器，切换时需要匹配的构建。
- **连接脚本与原生游戏系统**：HashLink 提供脚本上下文和原生模块基础，配合 hlscriptc 实现驻留执行及符合条件的热更新，也为图形、音频和物理组件提供 Haxe 与 C/C++ 的互操作。

## 字节码、JIT 与 AOT

配套 Haxe 编译器和打包工具生成 HLB6 字节码，HashLink 可在运行时将字节码编译为本机指令。x86/x64 的部分 JIT 编译工作支持并行配置；源码还提供解释执行和实验性的 ARM JIT 构建路径，原生调用能力取决于宿主、构建选项及相关组件。当前配套宿主要求 HLB6，旧字节码需要从源码重新编译。

Beap 可以使用 LLVM AOT 将字节码提前转换为目标机器码，并与原生宿主、运行库及其他依赖链接。当前配套发布目录覆盖 Windows、Linux x86-64 的 JIT/AOT，以及 Android arm64 的 AOT；其他平台需要匹配的构建和宿主接入。AOT 程序的动态脚本能力取决于所选宿主和运行配置。

字节码、运行时和原生模块需要采用匹配的版本与数据布局；当前 Wide64 运行时不接受标记为 Compact32 的产物。

## 垃圾回收与内存设施

Mark-Sweep 通过标记可达对象并清理其余对象管理托管堆；ZGC64 提供并发处理与对象搬迁，面向符合其运行时及原生模块合同的 64 位目标。项目可配置受支持的内存和工作线程参数并读取 GC 统计。GC 模式在启动时选择；部分 AOT 产物固定使用 Mark-Sweep，切换到 ZGC64 需要匹配的构建。

运行时还提供存活对象检查、紧凑对象数组、字节缓冲区视图、批量复制和 GUID 等底层能力，具体可用范围取决于运行时版本。原生资源及其对托管对象的引用仍需要由相应组件管理。

## 原生模块与系统服务

HashLink ABI 将 Haxe 代码与 C/C++ 组件连接。配套 Native4 能力支持受检查的值和缓冲区访问、强弱引用、原生资源和回调登记，供图形、音频、物理、平台服务等模块使用；运行时、头文件和模块需要匹配。

标准运行设施涵盖字符串与 Unicode、数组和映射、数学、日期、正则表达式、文件、异常、线程同步、进程和套接字。运行时也提供类型反射与调试支持。

| 可选原生组件 | 支持的功能 |
| --- | --- |
| 数据格式 | JPEG、PNG 和 DXT 解码，图像缩放，Ogg Vorbis 与 MP3 解码，以及 Deflate 压缩处理。 |
| 网络与事件 | TCP、UDP 和 TLS；libuv 组件提供事件循环、异步 TCP 流和文件变化监听。 |
| 数据库与声音 | SQLite、MySQL 和 OpenAL 接入。 |
| 窗口与图形 | SDL、DirectX 和部分平台界面能力，适用范围由对应组件决定。 |
| Arcora 原生辅助 | 二维顶点变换、网格优化、切线生成、凸分解和 RenderDoc 捕获等能力。 |

这些组件需要相应原生模块和外部依赖，具体可用范围取决于目标平台、运行时和构建配置。

HashLink 还提供脚本上下文基础，供 [hlscriptc](hlscriptc.md) 在受支持的进程内路径上执行脚本，并结合模块驻留和延迟回收实现热更新。

## 诊断能力

带性能采集支持的运行库可向 hlmp 提供线程、分配、GC、异常及原生调用事件。源码位置、调用信息、调试符号以及 GPU 或线程调度数据取决于构建配置、平台和设备。
