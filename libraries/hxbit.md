# hxbit

[返回总览](../README.md)

hxbit 是 Haxe 的类型化二进制序列化与网络状态同步库。它通过编译期代码生成处理对象编解码，并支持共享引用、版本化存档、对象状态复制和远程调用；实际网络传输由应用提供。

## 功能总览

| 功能 | 支持的能力 |
| --- | --- |
| 二进制序列化 | 支持基本类型、字符串、字节、枚举、集合、结构和已声明对象。 |
| 对象关系 | 保留对象身份、共享引用和循环引用，提供紧凑的轻量结构编码。 |
| 版本化存档 | 使用携带 schema 的 HXS 存档处理部分字段和类型变化。 |
| 网络状态同步 | 支持完整状态同步、属性变更复制、对象生命周期与权限控制。 |
| 远程调用 | 支持面向所有端、客户端、服务端和对象拥有者的不同分发方式。 |
| 调试与安全边界 | 提供存档查看、网络统计和解码规模限制，可结合宿主传输与安全机制使用。 |

## 特色功能

- **保存已声明对象的引用关系**：编译期根据 Haxe 类型生成二进制处理代码，保存已声明字段，并保留对象身份、共享引用与循环引用，适合游戏存档和需要恢复对象关系的数据。
- **存档携带类型结构**：HXS 可保存 schema，读取时处理部分字段增删和类型转换；业务语义变化仍需要项目提供迁移规则。
- **状态复制与远程调用一起使用**：共享对象既可进行完整同步，也可按变化同步属性并发送远程调用，适合权威端与客户端协作；实际连接、认证和加密由宿主传输层提供。

## 二进制数据与对象

hxbit 根据业务类型声明生成二进制编码逻辑，支持基本值、字符串、字节数组、枚举、数组、向量、Map、匿名结构和对象。通过对象标识，序列化可以恢复共享引用和循环引用；对不需要独立对象身份的结构，也提供更轻量的编码方式。

整数使用相应的紧凑或固定宽度表示，支持 64 位整数；浮点数默认按 32 位保存。支持显式可空字段、枚举标志、部分动态值与自定义类型编解码。反序列化恢复对象状态时不执行业务构造函数，依赖构造过程的资源初始化需要由应用处理。

## 存档与版本兼容

普通序列化适合同版本的数据交换；HXS 存档同时保存所用类型的 schema。读取版本化存档时，可以处理字段新增、删除、类编号变化和部分字段类型转换，也支持为特定字段提供转换逻辑。字段的业务含义或单位发生变化时，仍需要项目定义迁移方式。

随库的查看工具可以检查 HXS 结构和对象内容，在受支持的环境中输出 JSON。轻量结构编码不提供普通对象的 schema 版本兼容机制；历史存档的实际兼容范围也取决于所使用的数据布局。

## 网络状态与远程调用

网络同步围绕共享对象和权威端组织。新客户端可以接收完整对象状态，运行中再按变化复制属性；完整状态发送与接收端处理分属不同阶段。同步支持访问权限控制、按条件发送和按量化步长过滤更新。

集合、结构及标志位的内部修改可以通过相应代理跟踪，包括受支持的嵌套容器；具体变化在某些情况下会导致整个容器重新发送。各节点执行相同确定性计算时，也可以仅更新本地状态而不发送对应变更。对象集合可保存与恢复，网络统计可以查看属性更新和远程调用的次数及字节量。

远程调用支持面向所有端、客户端、服务端、对象拥有者及立即执行等分发方式；部分定向调用支持异步返回结果。应用需要在权威端检查网络请求的业务参数与权限。

## 传输与数据边界

hxbit 不限定 TCP、WebSocket 或其他传输方式；连接认证、加密、防重放和重连由应用及传输层提供。网络消息支持文本及二进制数据，采用带长度的帧；解码时检查输入长度、UTF-8、对象引用及类型，并可限制集合、对象、嵌套深度和载荷规模。网络消息默认单帧上限为 16 MiB；已执行的业务回调产生的副作用不会因后续解码失败而自动撤销。

库还包含 vdom 示例组件，可通过 hxbit 消息向 JavaScript 端传递部分 jQuery 风格的网页操作；应用需要提供消息传输。
