# arcora-anim 动画

[返回总览](../README.md)

`arcora-anim` 是 Arcora 的高层动画运行时，覆盖动画片段、状态图、骨骼与姿态、运动匹配、GPU 蒙皮数据和动画资源流送。二维和三维对象可以通过适配器接收动画结果。

## 功能总览

| 功能 | 支持范围 |
| --- | --- |
| 动画片段 | 多轨道、属性绑定、循环、插值、事件和同步标记。 |
| 动画图 | 参数与状态机、一维或二维混合、图层、遮罩、过渡和根运动。 |
| 骨骼与 IK | 双骨骼和全身 IK、骨架重定向、控制绑定和姿态约束。 |
| 运动匹配 | 基于姿态与轨迹搜索动作，支持过滤、索引与分片加载。 |
| 物理与形变 | 物理动画、布娃娃混合、次级运动和姿态驱动的形变。 |
| GPU 动画 | 姿态图集、图层混合、骨架计算和蒙皮矩阵。 |
| 数据与优化 | 压缩片段、异步流送、状态快照、姿态共享、预算调度及调试。 |

## 特色功能

- **根据运动需求搜索动作**：运动匹配结合历史姿态、角色速度和预测轨迹，从动作库中筛选候选；可按标签和动作连续性控制选择，并按需加载较大的索引分片。
- **共享角色姿态**：多个角色可以按动画图、状态、相位和 LOD 分组，由代表角色发布姿态供同帧成员使用；动画预算还可按重要性调整更新频率。
- **GPU 姿态与运动矢量**：预制姿态图集可在 GPU 上进行图层混合和骨架计算，同时保留当前与上一帧蒙皮数据；状态切换、事件和根运动继续由 CPU 管理。该路径需要支持计算和存储缓冲区的设备，以及匹配的骨架顺序和未拆分蒙皮资源。
- **分块动画资源**：压缩片段支持按时间采样、分块读取和预取，并保留事件与同步标记，适合按需加载较长或较多的动作。

## 动画片段与状态图

动画轨道支持标量、整数、布尔值、二维和三维向量、四元数、颜色、旋转及精灵帧，并支持 Step、Linear、Hermite 和 Bézier 插值。片段可循环播放，按时间触发事件，并使用同步标记协调动作。

动画图根据布尔、整数、浮点和触发参数控制状态，支持条件、优先级、AnyState、归一化退出时间和直接播放。混合功能覆盖一维、二维混合树、交叉淡化、可中断过渡、同步标记及惯性化。

图层可使用遮罩覆盖或叠加动作；根运动可按图层提取位移和旋转、按需从输出姿态中移除，并处理循环跨周期。事件按时间顺序输出，动画状态可保存为快照，用于存档、回滚或同步；动画图更新时可依据稳定标识迁移状态。

## 骨骼、IK 与动作修正

骨骼功能支持双骨骼解析 IK、多末端 FABRIK 全身 IK、目标朝向、摆动和扭转限制、偏好弯曲方向、伸缩、极点、接触、骨盆和质心控制。

骨架重定向可在不等长骨架之间转换动作，支持参考姿态修正、扭转分配和缩放。控制绑定可以组合瞄准、姿态复制与混合、IK 和旋转限制等节点。

动作修正支持按剩余距离调整播放时间、修正运动终点和脚步长度，并将转身变化分配给骨盆与躯干。

## 运动匹配与姿态驱动

运动匹配根据姿态历史、速度、朝向和预测轨迹搜索动画库，支持特征归一化、标签过滤、连续性代价、候选追踪、IVF 索引和按需加载的索引分片。

物理动画可由动画姿态生成 PD 驱动目标，支持局部布娃娃混合和恢复。次级运动采用固定步长 Verlet 模拟，支持重力、阻尼、长度约束及球体碰撞。

神经网络和 RBF 修正形变可以根据姿态驱动肌肉、衣物或面部等标量形变；相应模型和修正数据需要由项目准备。

## GPU 动画与多角色优化

GPU 路径支持固定采样率姿态图集、覆盖和叠加图层、关节遮罩、惯性弹簧、骨架层级与蒙皮矩阵计算，并保留当前帧和上一帧的骨骼矩阵供运动矢量使用。状态选择、事件与根运动仍由 CPU 管理；GPU 路径需要计算着色器、存储缓冲区及匹配的骨骼和蒙皮数据。

动画预算调度可按重要性调整更新频率，并限制最长未更新间隔。姿态共享可根据动画图、状态、相位、图层和 LOD 分组，由代表实例发布姿态供同帧其他实例使用；也支持有界的姿态缓存和基于 Arcora 任务系统的并行更新。

## 动画资源与调试

| 格式 | 内容 |
| --- | --- |
| `HANM` | 动画图的 v4 二进制格式，也支持 JSON。 |
| `HANS` | 动画状态快照。 |
| `HACL` | 支持按时间采样、分块读取和预取的压缩动画片段。 |
| `HMIX` / `HMSH` | 运动匹配索引、数据库身份和可分别加载的索引分片。 |
| `HGPA` | GPU 姿态图集与骨架数据，不包含动画图、事件或根运动。 |

压缩片段采用固定采样率和量化数据，可分块读取并保留动画事件与同步标记；解码缓存和预取用于按需访问片段。压缩片段与运动匹配分片支持从内存、文件资源或自定义数据源同步、异步加载；基于任务系统的异步读取需要工作线程，资源尚未就绪时项目可以选择姿态回退方式。

调试功能包括骨架线条和可导出为 Chrome/Perfetto JSON 的时间线。素材导入与编辑分别见 [arcora-assets](arcora-assets.md) 和 [Arcora Editor](arcora-editor.md)。
