# arcora-forensic

[返回总览](../README.md)

`arcora-forensic` 为图片和视频提供取证水印：在内容发布前嵌入短标识，再从传播后的内容中检测标识。检测不需要原始图片或视频；识别出的标识可结合发行记录追溯对应批次或接收对象。

## 支持的功能

| 功能 | 支持内容 |
| --- | --- |
| 图片水印 | 在多种灰度和彩色图片中嵌入标识，并对图片进行盲检。 |
| 视频水印 | 在连续视频帧中写入时变水印，汇总多帧结果进行检测。 |
| 截取视频检测 | 对连续截取的视频搜索水印起始相位，也可结合原始帧号检测。 |
| 纠错与认证 | 使用卷积码、Viterbi 解码和 HMAC 检查提取结果。 |
| 色彩处理 | 支持常见 CPU 图像及视频像素格式，保留透明度并处理视频亮度范围。 |
| 检测报告 | 提供认证状态、置信度、相关性、覆盖率、纠错数量与帧信息。 |
| 视频文件 | 可选结合 `arcora-video` 解码视频文件并逐帧检测。 |

## 特色功能

- **无需原始素材的来源检测**：图片和视频可嵌入带认证的短标识，检测时不需要原始画面；项目可以将检测出的标识与发行记录关联，用于定位对应批次或接收对象。
- **双域扩频、纠错与认证**：标识同时写入局部亮度差分和 DCT 中频信息，检测时结合纠错与密钥认证，设计目标包括应对重编码、量化和轻度噪声。检测成功率和误报率需要结合实际素材与传播过程验证。
- **截取视频的起始相位搜索**：水印图样随时间槽轮换，检测连续截取的片段时可搜索未知起始相位；抽帧、重排或帧率变化仍需要额外保证帧的时间对应关系。
- **图片与视频色彩处理**：彩色图片处理保留 alpha，NV12/P010 视频只修改亮度平面；GPU 外部图像需要先转换为支持的 CPU 格式，视频文件检测需要配合视频库。

## 图片与视频格式

图片支持 R8、RGB8、RGBA、BGRA、ARGB 和 SRGB。彩色图片处理会保留 alpha；预乘 alpha 素材在处理前后进行相应转换，完全透明像素不承载有效信号。图片水印写入新图像副本，可以用于图片导出与发布流程。

视频支持 CPU 内存中的 NV12、P010 和 RGBA8 帧，可处理具有指定偏移和行步幅的解码缓冲区。NV12 和 P010 只修改亮度平面，并根据有限或完整亮度范围限幅。视频帧可以接入自定义解码流程；结合 `arcora-video` 后也可以处理可写的 CPU 视频帧或逐帧检测视频文件。GPU 外部图像需要先转换为支持的 CPU 格式。视频文件检测默认读取最多 300 帧，也可以读取到文件结束。

视频水印图样按时间槽轮换，默认周期为 12，可配置为 1 至 64。检测连续截取的视频时，可以搜索未知起始相位；保留原始帧号的流程也可以使用帧号进行检测。抽帧、丢帧、重排和帧率变化需要额外保证时间对应关系。

## 水印生成与盲检

当前 v1 profile 支持 1 至 16 字节载荷，并将版本、载荷和 96 位截断 HMAC-SHA-256 认证标签封装为固定 32 字节数据。水印使用码率 1/2、约束长度 K=7 的卷积码进行纠错，检测时通过软判决 Viterbi 解码和认证检查恢复结果。

水印信号使用 HMAC-SHA-256 派生密钥，并结合 ChaCha8 序列进行置换与扩频，写入局部亮度差分和 8×8 DCT 中频系数对。默认同时使用空域和频域，也可调整强度、启用范围及检测阈值。块内纹理和亮度变化会影响写入强度及画面变化，检测则汇总可用区域或多个视频帧的证据。嵌入报告可记录处理区域、样本数量和数值限幅情况。

容量按完整 8×8 块计算：嵌入至少需要 1,048 个载波样本，检测至少需要 524 个；默认双域模式下每个完整块提供两个样本。素材尺寸、启用的域和视频周期会影响可用容量与检测条件。

## 检测结果与发行管理

检测结果区分认证通过、认证通过但相关性较低、未发现水印和证据不足等情况，同时报告认证状态、置信度、相关性、纠正位数、覆盖率、帧数、相位以及空域和频域样本数。认证用于判断解码出的结果是否与密钥匹配，发行对象仍需由项目通过标识映射确定。

密钥至少需要 16 字节，也可生成随机密钥。嵌入和检测需要使用一致的密钥、上下文、尺寸和 profile；发行系统负责保护密钥并保存配置与标识映射。水印载荷适合保存短标识，不应直接包含秘密信息。

## 适用范围与依赖

算法面向重编码、量化、轻度噪声和连续视频起点变化。裁剪、缩放、旋转、透视等处理会改变检测条件；当前没有专门恢复几何变换前位置的同步步骤，也没有多份内容合谋去除水印的检测功能。检出率和误报率需要结合实际分辨率、编码与传播流程验证。

库的水印处理使用 Haxe CPU 实现，依赖 Arcora 和 `crypto`。视频文件检测还需要 HashLink、`arcora-video` 和相应构建配置。
