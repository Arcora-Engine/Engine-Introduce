# hldx Windows 窗口与 DirectX 图形

[返回总览](../README.md)

`hldx` 为 Haxe、HashLink 和 Arcora 提供 Windows 原生窗口、输入与 DirectX 图形能力，可作为 Windows 游戏和图形程序的底层组件。

## 功能总览

| 功能 | 支持范围 |
| --- | --- |
| 窗口与输入 | Win32 窗口、显示器、键鼠、游戏控制器、光标、缩放和拖放。 |
| 图形接口 | Direct3D 12、Direct3D 11、DXGI 和 HLSL 着色器编译。 |
| 显式资源管理 | GPU 资源、图形命令、内存、状态转换与 GPU 同步。 |
| 高级图形功能 | 光线追踪、Mesh Shader、可变速率着色和 Sampler Feedback。 |
| 多媒体与画面增强 | 视频解码帧互操作、厂商图形增强组件接入。 |
| 开发与诊断 | 设备能力和显存预算查询、调试层、GPU 验证、PIX 和时钟校准。 |

## 特色功能

- **Windows 的两条 Direct3D 路径**：Direct3D 12 提供显式资源、队列和同步管理，Direct3D 11 提供兼容绘制路径；窗口和输入也由同一组 Windows 组件提供。
- **现代 GPU 功能组合**：支持查询并使用设备具备的光线追踪、Mesh Shader、可变速率着色和 Sampler Feedback，适合需要了解目标显卡能力的渲染项目。
- **视频和画面增强互操作**：可在同一图形设备上接收 NV12、P010 视频帧，并向满足条件的厂商画面增强组件提供图形资源。
- **GPU 与显示诊断**：支持显存预算、时间戳、时钟校准、调试层、GPU 验证和 PIX；DXGI 帧统计可在系统提供反馈时估算呈现时间与刷新周期。

## 图形接口及其定位

| 图形接口 | 定位与范围 |
| --- | --- |
| **Direct3D 12** | Arcora 在 Windows 上的主要现代原生图形路径，支持显式资源、命令、队列和同步。 |
| **Direct3D 11** | Windows 兼容图形路径，支持传统绘制与资源处理。 |
| **DXGI** | 支持显示器、交换链、画面呈现、显存预算及相关设备能力。 |
| **HLSL / DXC** | 提供着色器编译，支持 Direct3D 11 字节码及 Shader Model 6 的 DXIL。 |

Direct3D 12 与 Direct3D 11 的实际功能分别取决于系统、显卡、驱动和项目配置。图形接口的接入范围与每台设备提供的高级能力需要分别确认。

## 窗口与输入

窗口支持标题、图标、尺寸、位置、显示器、透明度、窗口与全屏切换、尺寸限制、鼠标捕获及相对鼠标模式，也支持系统和自定义光标。

输入事件覆盖按键、重复按键、文字输入、鼠标位置与滚轮、窗口焦点、缩放、关闭和文件拖放；键盘输入区分按键含义和物理位置。游戏控制器可通过 XInput 或 DirectInput 发现设备、读取按钮与轴，并在设备支持时提供震动。

事件时间包含原始时间、主机单调时钟时间、时钟域和误差估计，可用于关联输入、音频和模拟时间。

## Direct3D 11 功能

Direct3D 11 路径提供设备、交换链、绘制上下文、缓冲区、纹理和渲染目标。绘制支持顶点与像素着色器、采样器、光栅化、深度与混合状态，以及普通、索引、实例和间接绘制。

资源操作包括映射、子资源更新、区域复制和纹理 mip 生成。错误诊断可报告 HRESULT、设备移除原因和原生源码位置；窗口尺寸变化及多个图形组件共享上下文时需要处理相应图形状态。

## Direct3D 12 与 GPU 底层

Direct3D 12 支持图形设备、交换链、命令队列、命令列表、根签名、描述符堆、图形与计算管线和 GPU 资源管理，并提供资源屏障与 fence 同步。

内存和资源能力包括 committed、placed、reserved 资源，显存堆、稀疏纹理映射、缓冲区与纹理区域复制、资源布局和描述符复制。还支持查询堆、条件渲染和间接执行；跨队列操作和资源使用需要按 GPU 工作进度同步。

在硬件和驱动支持时，可使用光线追踪加速结构、光线追踪管线和 ray query，以及 Mesh Shader、可变速率着色（VRS）和 Sampler Feedback。设备能力查询覆盖单项功能、DirectX 12 Ultimate 组合条件、显存预算、队列时间戳频率与时钟校准。

## 视频、画面增强与诊断

视频互操作功能可以在同一图形设备上接收媒体模块解码的 NV12、P010 多平面画面，并协调 GPU 同步与图像资源。画面增强扩展可以使用设备、纹理、图形命令和显示端点，接入满足条件的厂商组件。

着色器功能包括 HLSL 编译和字节码反汇编；Shader Model 6 / DXIL 路径需要匹配的 DXC 运行组件。

开发诊断支持 Direct3D 调试层、GPU 验证和 PIX。HDR 画面与实际显示反馈取决于显卡、显示器和系统配置；可用的 DXGI 帧统计可用于估算画面呈现时间、刷新周期和错过的刷新次数。

## 平台与运行条件

`hldx` 面向 Windows x64，提供 HashLink 字节码运行与提前编译程序所需的原生模块。Direct3D 11、Direct3D 12 和高级 GPU 功能分别依赖设备、驱动及系统组件。
