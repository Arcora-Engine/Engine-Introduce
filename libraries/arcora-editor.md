# Arcora Editor

[返回总览](../README.md)

Arcora Editor 是面向 Arcora 项目的可视化编辑器，用于管理项目素材、制作 2D/3D 场景、编辑材质与动画，以及预览和构建游戏。

## 支持的功能

| 功能 | 支持内容 |
| --- | --- |
| 项目与资源 | 管理项目、资源导入、内容浏览、搜索、依赖与资源集合。 |
| 场景编辑 | 编辑 2D/3D 场景、节点层级、组件属性、场景图层与多场景组合。 |
| Prefab | 将节点与组件保存为可复用模板，支持实例属性覆盖、还原和应用。 |
| 材质与动画 | 通过材质图、材质实例、时间线和动画状态机制作内容。 |
| 地形与粒子 | 编辑高度场、地表权重、植被和 GPU 粒子效果。 |
| 运行预览 | 在编辑器内运行场景，支持暂停、单帧推进、检查和性能信息。 |
| 开发与发布 | 提供项目预检、任务面板、Git 版本管理、项目构建及模块扩展能力。 |
| 可选系统模块 | 可接入物理、脚本、音视频和 RenderFX，具体功能取决于构建配置。 |
| 界面语言 | 内置简体中文和英语，支持扩展语言包。 |

## 特色功能

- **独立运行副本**：场景预览会创建与编辑场景分开的运行副本，支持暂停、单帧推进和查看运行状态。停止预览后，运行副本中的修改不会自动写回源场景，适合调试游戏行为。
- **可复用的场景组合**：Prefab 保存可复用的节点与组件，场景实例可以覆盖、还原或应用属性；Subscene 支持引用和嵌套独立场景，便于组合较大的项目。
- **基于依赖关系的资源管理**：内容浏览器可查看资源依赖，移动资源时维护项目引用，并保护打开的场景和仍被引用的素材。项目预检可以集中报告场景、Prefab 与资源问题。
- **按项目接入系统模块**：物理、脚本、音视频和画面增强通过可选模块提供编辑与预览能力，资源导入、组件和视口工具也可扩展；可用功能取决于模块与宿主配置。

## 项目与资源管理

项目使用项目目录或 `arcora.project.json` 记录入口场景、启用模块和工具链配置。编辑器可同时打开多个 `.hscene.json` 场景；外部文件变化时，未修改的文档可以重新加载，有未保存内容的文档会报告冲突。自动恢复快照会关联场景身份和源文件状态。

Content Browser 管理场景、模型、纹理、声音等资源，支持按名称、路径、类型和标签组合搜索，也支持排除条件。资源可批量导入、重新导入、移动或放入项目回收站；引用图和检查工具可查找资源依赖。静态集合保存指定资源，动态集合根据搜索条件随索引更新。资源移动时会维护项目引用，打开的场景及仍被其他资源引用的素材受保护。

任务和问题面板集中显示导入、资源检查、预览和打包的进度与错误，并允许取消支持取消的任务。项目预检可以检查打开或已保存的场景、资源依赖、Prefab 和模块提供的其他问题；支持手动执行、项目保存后执行，以及按项目变化自动执行。预检报告供检查，不会隐式阻止打包。编辑器内置简体中文和英语，可通过语言包扩展其他语言。

## 场景、对象与 Prefab

Viewport 支持二维与三维场景、对象选择、移动、旋转和缩放，并提供步长、表面和顶点吸附。三维视图支持环视、平移、缩放和键盘移动，也可隔离所选层级。World Outliner 用于组织节点父子关系、文件夹和搜索结果；场景图层可分别控制编辑可见性、锁定与加载。

Inspector 支持多选属性编辑、混合值显示和恢复默认值。节点可以添加相机、灯光、模型、精灵、粒子等组件，节点与组件可分别启用或停用。复制、剪切、粘贴、拖放和变换操作支持撤销与重做；工作区支持分栏、标签、浮动窗口及布局保存。

Prefab 使用 `.hprefab` 保存可复用的节点和组件。场景实例可以覆盖名称、变换、组件属性和材质，再将覆盖还原或应用回模板。Subscene 通过场景引用组合独立场景，支持嵌套与按需加载，并检查循环引用。场景使用右手 Y-up 坐标系和米制单位，资源和场景引用使用稳定 GUID 保存。

## 材质、动画、地形与粒子

Material Graph 通过节点编辑颜色、贴图、金属度、粗糙度、透明度、发光和表面细节。材质图保存为 `.hmat`，材质实例参数保存为 `.hmatinst`；编辑器提供球体、立方体和面片预览，并将材质及依赖纳入资源构建。

Timeline/Cutscene 支持变换、颜色等属性的关键帧、相机切换和事件，提供播放、暂停、逐帧预览、关键帧复制粘贴、线性或阶梯插值，以及缓入、缓出和缓入缓出效果。动画状态机工具支持状态与切换条件、一维和二维动作混合，以及覆盖层和叠加层；姿态预览需要动画运行库及相应素材。

Terrain 工具支持高度场抬高、降低、平滑、展平和四层地表权重绘制；高度图支持 R16 或 16 位灰度 PNG；PNG 需要无透明通道、未隔行，且为边长 2 至 4096 的正方形。地表权重和植被密度可使用原始数据或 PNG 遮罩交换。植被可设置密度、缩放、阴影、风动并引用项目模型。GPU 粒子编辑器支持点、球、锥、盒等发射形状，以及速度、寿命、颜色、大小、碰撞、拖尾和阴影。地形碰撞、完整世界分区和部分粒子效果取决于项目接入及设备能力。

## 场景预览与性能

Preview 为编辑场景创建独立运行副本，支持启动、暂停、单帧推进、继续和停止，并可检查运行时层级、属性和消息。停止后恢复编辑场景，运行副本中的修改不会自动写回源文件。

桌面 Preview 使用编辑器视口承载运行场景；无窗口 Preview 可在独立进程中通过 TCP 连接。性能面板可显示帧率、帧耗时，以及更新、渲染和 GPU 提交等阶段的数据。

## 版本管理与项目构建

Git 面板支持分支、状态、差异、提交历史、逐文件暂存与取消暂存，以及提交前审核。项目位于仓库子目录时，可以按项目范围提交已暂存内容。恢复工作文件提供预览；冲突处理提供版本对照、文本编辑和标记解决。批量暂存及部分受保护的冲突操作使用 Windows 实现。

项目构建可整理场景、Prefab、资源和依赖，生成游戏包。编辑器采用模块化组织，资源导入、组件、属性面板和视口工具可扩展；脚本、原生代码或独立进程模块的动态加载取决于宿主提供的加载能力。

可选模块提供 Jolt 刚体与碰撞体编辑及物理预览、hlscriptc 脚本组件、RenderFX 画面增强设置，以及音频 PCM 和视频预览适配。可用能力取决于模块、原生组件和宿主配置。

## 平台与依赖

项目提供 Windows 桌面入口，也提供 Android arm64 宿主和项目资源接入。桌面完整配置需要匹配的 Haxe、HashLink、SDL3、Vulkan、着色器资源和所选模块；其他目标及具体功能取决于平台工具链、设备与已接入的原生模块。
