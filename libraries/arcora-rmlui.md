# arcora-rmlui

[返回总览](../README.md)

`arcora-rmlui` 将 RmlUi 6.3 接入 Arcora，为游戏和工具提供以 RML、RCSS 描述的界面系统。界面可与场景画面合成，适合制作菜单、HUD、设置界面、背包和编辑器面板。

## 支持的功能

| 功能 | 支持内容 |
| --- | --- |
| 界面布局 | 使用 RML 描述结构、RCSS 定义样式，支持文本、图片、表单和常用控件。 |
| 数据与交互 | 支持数据绑定、条件显示、列表、双向表单和界面事件。 |
| 输入与系统服务 | 支持鼠标、键盘、触摸、手柄、文本输入及 IME 等宿主服务。 |
| 组件与工具 | 支持 RMLX 组件、模板、主题、布局、构建时生成和界面热重载。 |
| 字体与多媒体 | 支持字体、复杂文字排版、SVG、Lottie 和动态图片。 |
| 绘制与特效 | 支持几何、裁剪、渐变、图层、遮罩、模糊、阴影和颜色滤镜。 |
| 原生接入 | 通过 Arcora 渲染接口输出，提供 HashLink 动态模块与 LLVM AOT 接入。 |

## 特色功能

- **RMLX 声明式组件**：通过带类型的属性、模板、主题和数据绑定组织界面，构建时生成 RML/RCSS、资源清单和源码映射，适合复用菜单、设置页及工具面板。
- **与场景共用图形管线**：界面通过 Arcora 的 RHI 与游戏画面合成，也可绘制到指定目标；图层、遮罩、模糊和阴影等效果使用离屏渲染，实际效果取决于图形后端和设备。
- **数据驱动的动态界面**：界面文本、条件、列表与表单可随应用数据更新，并将表单修改和事件传回应用。图片可使用文件、SVG、Lottie 或运行时像素，适合制作动态 HUD 和编辑器面板。
- **面向迭代与恢复**：界面支持热重载，新文档加载失败时保留原界面；图形设备变化后，界面资源可随宿主的设备恢复流程重新准备。

## 界面布局与控件

RmlUi 负责界面文档、布局、样式计算和绘制内容生成；应用逻辑和网络访问由宿主提供。项目可以创建多个界面区域，分别管理窗口、游戏画面或工具面板，并在界面中使用文本、图片、按钮、输入框、选择框、进度条和标签页等控件。界面支持 flex 布局、样式变量、伪类、焦点、滚动、过渡与动画，也支持运行时修改。

界面文档可启用热重载；新内容加载失败时保留原界面。调试器和统计信息可用于查看界面、事件、纹理及绘制情况。文档和数据支持批量更新，以合并界面变更通知。

## 数据绑定与输入

数据模型支持数字、字符串、对象和数组，可以连接到界面的文本、条件显示、列表、class、style、表单值和事件。界面可随数据变化更新；表单修改与声明的事件可以传回应用。数组支持替换、插入、删除和移动等操作，适合动态菜单、物品列表与设置界面。

输入覆盖鼠标、键盘、触摸、手柄和 Unicode 文本输入；手柄轴可以用于界面焦点导航。输入也可结合视口偏移、DPI 与画面留边转换坐标。输入法组合与候选框、软键盘、光标和剪贴板通过宿主接入平台服务；移动设备上的具体表现取决于系统和宿主实现。

## RMLX、字体与动态内容

RMLX 提供构建期声明式组件，支持带类型的属性、slot、数据上下文、单向与表单双向绑定、数据和控件模板、主题、触发器、资源字典以及 Grid 布局。构建时会生成标准 RML/RCSS、加载代码、资源清单和源码映射，也可以监听源文件及依赖变化并重新生成受影响的内容。

图片可来自文件、内联 SVG、Lottie 或应用提供的 RGBA8 像素。字体由项目准备；HarfBuzz 可处理复杂文字排版，支持常用语言和文字方向配置，应用也可提供翻译内容。项目可以接入 Lua 脚本，并扩展界面元素、装饰器、字体效果和插件。当前默认原生构建包含 Lua、SVG、Lottie 和 HarfBuzz；实际功能仍取决于目标平台是否启用相应模块。

## 图形渲染与资源恢复

界面绘制通过 Arcora 的渲染硬件接口完成，可以在场景之后合成，也可以绘制到指定目标。基础渲染覆盖几何、变换和裁剪；高级效果包括渐变、图层、遮罩、背景滤镜、模糊、阴影与颜色矩阵，并使用离屏渲染组织相关处理。

稳定界面可复用已准备的绘制数据、GPU 缓存和临时纹理。设备变化或资源失效时，界面资源可以按宿主的设备恢复流程重新准备。着色器通过 `.asip` 或预编译 `.aslb` 提供；部分效果可使用软件回退，实际范围取决于图形后端和设备。

## 平台与运行条件

| 平台 | 图形接入范围 |
| --- | --- |
| Windows | 提供 Direct3D 11、Direct3D 12、Vulkan 和 OpenGL 接入。 |
| Linux | 提供相应 Vulkan 和 OpenGL 构建入口。 |
| Android | 提供 Vulkan 或 OpenGL ES 构建入口，面向 arm64、API 24 及以上。 |
| macOS | 提供 Arcora OpenGL 兼容路径的构建入口。 |
| iOS | 提供 arm64、iOS 12 及以上的入口；OpenGL ES 需要兼容宿主。 |
| Metal | 需要 Apple 宿主与 Arcora Metal RHI 接入，当前库没有现成的 Metal 后端。 |

移动宿主需要提供触摸、软键盘、输入法、剪贴板和生命周期接入。界面资源按只读资源目录访问，网络内容和字体由项目准备；RmlUi 使用自己的界面布局系统，没有浏览器网页兼容层。不同设备的高级效果取决于所选 RHI、驱动和着色器。
