# Beap

[返回总览](../README.md)

Beap 是面向 Arcora 和 Haxe 项目的多平台构建工具。它根据项目配置组织源码、资源、依赖和原生组件，协调 Haxe、HashLink、LLVM 与平台工具链，生成开发用字节码或可部署的原生应用。

## 功能总览

| 功能 | 支持的能力 |
| --- | --- |
| 项目配置 | 管理应用标识、版本、源码、依赖、资源、窗口和平台设置。 |
| 开发与原生构建 | 支持 HashLink 字节码开发，也支持通过 LLVM AOT 生成原生程序。 |
| 多平台发布 | 提供 Windows、Linux、Android、macOS 和 iOS 的目标配置与打包路径。 |
| 资源与着色器 | 收集项目资源，准备 Arcora 着色器输入和目标平台的预编译着色器库。 |
| 原生扩展 | 根据平台、架构和构建方式选择原生组件，并完成链接、注册与打包。 |
| 增量构建 | 缓存编译阶段产物，依据源码、依赖、配置和工具链变化判断复用。 |
| 构建优化 | 支持 LLVM AOT 的 PGO、按目标生成调试信息以及工具链和原生依赖检查。 |

## 特色功能

- **同一工程覆盖开发与发布**：项目配置统一组织源码、资源和依赖；开发阶段使用 HLB6 与 HashLink JIT，原生目标通过 LLVM AOT 生成程序。各平台仍需对应的宿主和工具链。
- **构建时统筹引擎资源和原生组件**：资源、着色器程序、原生扩展及其依赖可以随目标平台一起选择、链接和打包，适合包含多种引擎扩展的项目。
- **分阶段复用构建结果**：Haxe 字节码、LLVM 对象及最终产物分别参与缓存，输入和工具链未变化时可复用；原生构建还支持使用匹配目标采集的 PGO 数据。

## 构建方式

项目主要使用 project.xml 声明源码路径、依赖库、资源、窗口、应用版本与平台设置，也可以配置编译开关、HashLink 运行时、垃圾回收和原生编译选项。窗口和原生依赖支持按平台条件选择；Android 项目可声明最低与目标 SDK 以及应用类别。Beap 提供项目初始化、构建、运行、清理、工具链准备和原生依赖检查等能力。

HashLink 开发目标生成 HLB6 字节码，供匹配的运行时以 JIT 方式执行。原生发布目标使用 LLVM AOT 将带类型的 HashLink 字节码转换为目标对象，再链接平台宿主、运行库和项目依赖。当前配套工具链使用 HLB6 和匹配的数据布局、ABI 与 schema；旧字节码需要重新编译。

## 支持的平台

| 目标 | 产物和条件 |
| --- | --- |
| HashLink 开发目标 | 生成 .hl 字节码，依赖匹配宿主架构的 HashLink 运行时。 |
| Windows x86-64 | 使用 Windows 构建，生成 LLVM AOT 原生程序和相关文件，可包含调试符号。 |
| Android arm64-v8a | 生成 LLVM AOT APK，需要 Android SDK、NDK 等工具。 |
| Linux x86-64 / arm64 | 使用 Linux 构建，生成 LLVM AOT 可执行文件与运行库，需要对应工具链。 |
| macOS x86-64 / arm64 | 使用 macOS 构建，生成 LLVM AOT 可执行文件与运行库，需要对应工具链。 |
| iOS arm64 设备 | 生成 LLVM AOT 应用，需要 macOS、Xcode、iPhoneOS SDK 和适用的签名配置。 |

原生宿主默认不启用动态脚本；具备匹配桥接组件的平台可以按配置使用解释执行或 JIT。iOS 目标使用静态原生扩展，当前宿主配置不启用动态脚本。生成 AOT 程序和启用脚本运行时是分别选择的能力。

## 资源、着色器与原生扩展

Beap 按项目配置收集图片、声音、场景等资源，并准备 Arcora 的 .asip 着色器输入、.aslb 预编译库和目标平台所需的编译器组件。项目采用的着色器资源和运行方式决定实际部署内容。

原生扩展清单可以声明支持的平台、架构、源码或预编译构建方式、链接项与运行文件。Beap 会解析扩展及其传递依赖，选择适用的组件并安排链接与打包；纯 Haxe 库可以不提供原生扩展清单。运行库、原生模块与 AOT 产物需要满足相同 ABI 和布局要求。

## 增量构建与优化

Haxe 编译、HLB6、LLVM 对象、固定宿主与最终产物分别参与缓存。源码、依赖、资源、项目选项或工具链变化会影响复用；资源删除也会反映到后续打包结果。配套编译器提供构建进度与部分实验性的并行处理能力。

LLVM AOT 支持使用匹配程序及目标配置收集的 .hlpgo 数据进行函数入口 PGO。调试信息可按目标选择：Windows 支持 CodeView，ELF 目标支持 DWARF。构建工具还提供中英文命令行与 JSON 语言包。
