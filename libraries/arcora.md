# Arcora 核心引擎

[返回总览](../README.md)

`arcora` 是基于 Haxe 的 2D、3D 游戏与实时图形引擎核心。它提供场景与组件、渲染、输入、资源和任务等基础能力，并通过配套库扩展动画、物理、音视频、界面与编辑器。

## 功能总览

| 功能 | 支持范围 |
| --- | --- |
| 应用和场景 | 游戏循环、场景切换和叠加、对象与组件、多视图、固定步更新。 |
| 二维渲染 | 精灵、图形、文字、界面、骨骼动画、粒子、滤镜、灯光和阴影。 |
| 三维渲染 | 多种渲染管线、PBR 材质、光照与阴影、环境、粒子和后处理。 |
| 大型场景 | 世界流送、LOD/HLOD、地形植被、GPU 场景、虚拟纹理与几何。 |
| 图形底层 | Vulkan、Direct3D、OpenGL、WebGL、NullRHI、Metal 和 WebGPU 接入，以及 RHI、FrameGraph、资源与着色器管理。 |
| 输入与声音 | 键盘、鼠标、触摸、手柄、输入动作映射，以及二维和三维声音。 |
| 资源与运行时 | 资源加载和缓存、现代 2D 资源热重载、文件系统、并行任务、网络和存档。 |
| 内容与脚本 | 资源格式与几何工具，以及通过配套库接入动画、物理和动态脚本。 |

## 特色功能

- **2D 与 3D 视图组合**：二维布局可以嵌入三维场景，三维场景也可以显示二维视图；多个视图可共享同一源场景，并分别设置相机和刷新策略。这些能力可用于角色预览和场景内界面。
- **从渲染图到图形设备**：FrameGraph 按资源依赖组织渲染任务，RHI 管理设备、资源和同步；着色器输入与后端程序可分别打包。Vulkan 和 Direct3D 12 是主要原生路径，NullRHI 可用于无窗口验证。
- **大型场景按需组织**：世界单元可按距离与预算流送，纹理 mip 根据屏幕投影需求与预算调度；还可结合 LOD/HLOD、GPU 实例剔除、虚拟纹理、虚拟几何和虚拟阴影。具体能力需要相应内容资源、图形设备和项目配置。
- **现代 2D 光影与粒子**：可为二维场景启用灯光、材质和阴影，在满足设备条件时使用 GPU 粒子；子发射器、碰撞事件和预热使用 CPU 路径。

## 图形底层支持的后端

Arcora 的图形底层覆盖以下后端：

| 图形后端 | 定位与范围 |
| --- | --- |
| **Vulkan** | 主要原生图形路径，覆盖 Windows、Linux 等目标上的现代渲染能力。 |
| **Direct3D 12** | Windows 主要原生图形路径，支持显式资源、队列和同步管理。 |
| **OpenGL / OpenGL ES** | 原生平台兼容路径，具体功能取决于上下文版本和扩展。 |
| **Direct3D 11** | Windows 兼容路径，功能范围与现代原生路径有所区别。 |
| **WebGL** | JavaScript 浏览器应用的兼容图形路径。 |
| **Metal** | 已有宿主桥接和部分平台适配源码；Apple 目标构建、着色器和设备接入仍需完成。 |
| **WebGPU** | 实验性浏览器图形接入，具体能力取决于宿主与设备。 |
| **NullRHI** | 无窗口验证后端，用于 RHI 一致性和渲染图验证，不执行 GPU 着色器。 |

Vulkan 和 Direct3D 12 是核心库重点支持的现代原生后端。OpenGL、Direct3D 11 与 WebGL 面向兼容场景，部分高级渲染功能受到接口和设备能力限制。Metal 与 WebGPU 的源码接入状态不代表所有引擎功能均已在相应平台可用。

### 渲染架构和 GPU 能力

渲染硬件接口（RHI）统一组织图形设备、图形/计算/复制队列、命令、交换链、纹理、缓冲区、采样器和渲染管线，并提供设备能力查询、资源状态转换、上传、复制、同步和 GPU 工作完成后的资源回收。设备丢失后，部分场景资源可以根据保留的数据重新创建。

图形资源覆盖顶点、索引、统一与存储缓冲区，采样与存储纹理，以及描述符组、渲染目标和深度/模板附件。渲染管线可配置光栅化、深度、模板、混合与多重采样；内存管理提供临时资源池、堆、资源别名和稀疏资源等能力。

纹理格式包括 RGBA/BGRA、浮点和深度格式、HDR10 使用的 RGB10A2，以及 BC1–BC7、ETC2/EAC RGBA8、ASTC LDR 4×4 和 PVRTC1 RGBA 4 bpp 压缩格式。各格式能否用于采样、渲染、存储、混合或回读取决于后端和设备。

FrameGraph 根据渲染任务对资源的读写关系组织一帧的执行，支持资源屏障、临时资源复用、队列调度和并行命令录制，并裁剪不影响输出或副作用的任务。引擎提供渲染线程和可选的独立 RHI 线程；OpenGL、WebGL 和 Direct3D 11 的上下文相关路径采用串行执行。

图形底层还支持条件回读、资源索引、GPU 时间戳、可选的 GPU 与主机时钟校准、管线状态预创建与 `HPC1` 管线缓存。资源同步覆盖队列等待、信号、fence 和时间线，支持在 GPU 工作完成后释放资源。稀疏资源、独立队列、Bindless 索引、Mesh Shader 和光线追踪等高级能力取决于后端和设备。

### 着色器与图形程序

着色器使用 HxSL 及部分原生着色器源码，支持变体、资源布局和目标后端程序。`.asip` 用于组织着色器输入与契约，`.aslb` 用于交付编译后的后端程序；部分着色器支持重新编译与热替换。着色器资源需要与运行环境和目标后端匹配。

## 场景、对象与游戏循环

引擎提供场景创建、切换、叠加、卸载和更新；场景可以暂停模拟并继续渲染。对象和组件组织父子关系、变换、显示、声音、相机与游戏逻辑，支持启动、固定步更新、逐帧更新和销毁等生命周期。

三维场景以米为单位、Y 轴向上，角色前方沿负 Z 方向。

## 二维画面与界面

二维系统支持图片、精灵、线条、多边形、文字、批量绘制，以及层级、变换、透明度、混合、裁剪和遮罩。基础界面组件包括文本输入、复选框、滑块、下拉框和布局容器；也可选用外部 `domkit` 通过标记与样式组织界面。

二维画面提供模糊、泛光、阴影、发光、描边、颜色调整、位移和色调映射滤镜。现代 2D 路径还支持点光、聚光、方向光、表面材质、遮挡物及硬阴影或软阴影，需在项目中显式启用，具体阴影方式取决于设备能力。

二维动画支持逐帧播放、骨骼层级、CPU/GPU 网格蒙皮、绘制顺序和 IK。粒子支持发射形状、颜色、速度、重力、碰撞与尾迹，符合条件的设备可使用 GPU 模拟和间接绘制；子发射器、碰撞事件和预热使用 CPU 路径。

## 三维渲染、材质与光照

三维场景支持 HMD 模型、内置几何体和程序生成网格，提供实例绘制、骨骼蒙皮与形变。渲染路径包括 Deferred、Forward+、Forward 和 SimpleForward，适用于不同的场景与设备需求。

PBR 材质支持基础色、金属度、粗糙度、透明度、法线和自发光，以及地形、分层、清漆、透光、绒面和次表面散射。部分高级材质还支持折射、虹彩、色散、镜面反射和各向异性；材质图通过数值、纹理和运算节点组织表面效果。

光照支持方向光、点光、聚光、矩形和胶囊面光源，以及聚类光照、阴影、反射探针与环境贴图。桌面路径提供光度单位、色温、IES 灯光分布和投射纹理。环境支持天空、大气、体积云、体积光和水面，水面可配置波浪、反射、折射及水下效果。

间接光照包括预计算光照、DDGI、SSGI 和 RTGI，并提供硬件 ray query 与 ray-tracing pipeline 接入。后处理包括 SSAO、GTAO、SSR、Bloom、曝光、颜色调整与 LUT、tone mapping、TAA 和时序超分辨率；透明渲染支持排序混合，部分配置提供加权透明与场景折射，Deferred 路径支持材质贴花。不同效果需要相应内容资源和设备能力。

三维粒子支持精灵、尾迹、阴影与场景深度碰撞；深度碰撞基于当前视图中已绘制的不透明表面。

## 大型世界与资源

世界流送按距离、优先级和预算加载场景单元及纹理 mip；LOD/HLOD 使用预先准备的简化资源。大世界坐标与浮动原点用于管理远离原点的场景内容。

地形支持高度数据、多层地表和植被实例，植被可配置风动。支持的设备可使用 GPU 场景实例管理、视锥与遮挡剔除、模型细节等级选择和间接绘制，也可使用虚拟纹理、虚拟几何与虚拟阴影按需处理数据。部分原生设备还支持任务/网格着色器和设备生成绘制命令，具体执行范围取决于后端能力。相关功能依赖资源制作、设备能力和项目配置。

核心资源系统可按路径加载和缓存图片、模型、字体、声音和文本，也支持目录枚举。HMD 用于运行时模型，HPAK 用于组织交付资源。现代 2D 材质、骨骼、动画和粒子资源支持热重载；资源切换失败时保留旧版本，已有运行时实例的迁移由应用处理。资源导入与打包另见 [arcora-assets](arcora-assets.md)。

## 输入、声音与运行时服务

输入系统支持键盘、鼠标、触摸和手柄，并可将设备输入映射为动作、触发条件与不同优先级的上下文。

声音功能包括二维和三维声源、监听位置、音量控制与流式 PCM，支持波形、峰值、RMS、dBFS 和 FFT 频谱分析；场景声学可描述遮挡、房间、门洞与混响。

声音资源支持 WAV/RF64 的 PCM 与浮点数据。MP3 直接解码面向 HashLink 和 JavaScript，Ogg Vorbis 直接解码需要 HashLink 或相应组件，内置 MIDI 合成面向系统目标。可选的通用解码后端还可处理 Opus、FLAC、AAC、ALAC、AIFF、WMA、WebM 音轨和常见 Tracker 音乐等格式；具体能力取决于目标平台、解码组件和外部工具。

运行时提供按优先级与依赖调度的并行任务、分块工作、任务窃取、独立阻塞 I/O 工作线程、主线程后续任务和协作式取消；Windows 和 Linux 可配置线程亲和性。本地、内嵌、内存与组合文件系统可以配合网络读取和套接字使用。

版本化存档支持文件与浏览器存储、SHA-256 完整性检查、损坏时回退到上一代和顺序迁移。基础工具还包括像素读取与转换、图片区域复制、PNG 输出、随机数、噪声、二维几何和多边形布尔运算，以及二维和三维碰撞查询。完整刚体模拟由 [arcora-jolt](arcora-jolt.md) 提供。

## 平台与配套功能

核心库的主要发布范围是 Windows x64、HashLink 或 LLVM AOT，以及 Vulkan 和 Direct3D 12。JavaScript 目标可用于浏览器应用；其他原生平台的可用能力取决于原生模块、窗口后端、驱动和项目构建。

`arcora` 源自 Heaps 代码线，是独立的非官方分支；渲染、资源、线程和坐标约定与上游存在差异。动画、物理、画面增强与脚本能力分别见 [arcora-anim](arcora-anim.md)、[arcora-jolt](arcora-jolt.md)、[arcora-renderfx](arcora-renderfx.md) 和 [hlscriptc](hlscriptc.md)。
