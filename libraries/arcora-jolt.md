# arcora-jolt 物理

[返回总览](../README.md)

`arcora-jolt` 将 Jolt Physics 接入 Arcora，提供刚体、碰撞检测、约束、角色、车辆、布娃娃和软体模拟。原生物理核心通过版本化 C ABI 与 Haxe/HashLink 连接，可用于游戏场景的固定步物理更新。

## 功能总览

| 功能 | 支持范围 |
| --- | --- |
| 刚体模拟 | 静态、动态、运动学物体、受力、冲量、浮力和连续碰撞检测。 |
| 碰撞形状 | 基础几何体、凸包、三角网格、高度场、复合与变换形状。 |
| 碰撞查询 | 射线、点、包围盒、形状重叠和形状投射，支持过滤和批量查询。 |
| 约束与关节 | 固定、铰链、距离、滑动、六自由度、齿轮及路径等约束。 |
| 角色与车辆 | 虚拟角色、刚体角色、轮式车辆、履带车辆和摩托车。 |
| 身体与形变 | 布娃娃、动画驱动和软体顶点与约束模拟。 |
| 场景集成 | 固定步同步、碰撞事件、传感器、快照、调试显示与统计。 |

## 特色功能

- **角色、车辆与可变形物体共同模拟**：刚体、虚拟或刚体角色、轮式与履带车辆、摩托车、布娃娃和软体可组成游戏物理世界，覆盖常见的角色移动与载具场景。
- **适合游戏循环的同步方式**：物理模拟按固定时间步更新，运动学输入和动态物体结果可与场景同步；渲染使用物理步之间的插值，碰撞查询和事件支持批量处理。
- **保存与恢复物理状态**：快照可用于回放或回滚刚体、接触、约束、角色、车辆、布娃娃及软体状态；恢复依赖匹配的库二进制、世界拓扑和物体身份。

## 刚体和碰撞形状

物理世界支持静态、动态和运动学物体，可配置质量、速度、摩擦、弹性、阻尼、碰撞层及休眠状态，并施加力、扭矩、冲量和浮力；快速物体可启用连续碰撞检测。

碰撞形状包括空形状、盒体、球体、胶囊体、圆柱体、锥形胶囊体、锥形圆柱体、平面、三角形、凸包、三角网格、高度场和复合形状，也支持缩放、旋转、平移和质心偏移。可变复合形状允许增删或修改子形状并调整质心，形状可以共享、保存和恢复。

高度场支持读取样本、投影和更新区域。三角网格和高度场用于静态场景，动态物体可以使用合适的凸形或复合形状。

传感器用于产生进入、离开和接触事件。碰撞层、碰撞组、子组和过滤表可控制物体之间是否发生碰撞，也可为接触设置过滤规则、摩擦及弹性组合方式。

## 碰撞查询与事件

查询支持点、包围盒和形状重叠测试、射线与形状投射，可返回第一个、最近或全部符合条件的结果，也支持批量射线查询。过滤条件包括碰撞层、物体、子形状、传感器和表面朝向。

BroadPhase 使用包围范围筛选候选，NarrowPhase 检查实际形状；形状本身还提供边界、表面法线、三角形、材质、凸包几何、子形状信息、浸没体积和局部射线或点查询。

碰撞、传感器、物体激活和约束断开事件可在物理步骤后读取。事件队列具有容量限制，可按配置丢弃旧事件、新事件或在适用情况下报告步骤失败。

## 约束、角色与车辆

约束覆盖固定、点、距离、铰链、滑动、圆锥、摆动与扭转、六自由度、齿轮、齿轮齿条、滑轮和路径等类型；适用的约束支持运行时调整限位、弹簧、摩擦和 motor 目标，并读取求解器冲量。

角色控制包括虚拟角色与基于刚体的角色，可处理地面状态、坡度、台阶和站立、蹲伏时的形状切换。

车辆支持轮式、履带式和摩托车控制器，可配置车轮、悬架、发动机、变速器、差速器、履带和车轮碰撞，提供射线、球体或圆柱体方式的车轮碰撞检测及运行时车轮状态。布娃娃支持骨架、关节与碰撞组，并可通过姿态或速度驱动，与动画混合。

软体模拟支持顶点、面和多种连接约束，包括边、杆、长距离附着、弯曲、体积与蒙皮，也支持材质、接触策略和运行时参数调整；模拟结果可用于更新渲染模型。

## 场景同步、快照与调试

物理模拟可以接入 Arcora 的固定步更新，同步运动学输入与动态刚体结果，并在物理步之间对画面进行插值；场景变换同步考虑父级坐标空间。批量创建、销毁、位置读取、运动目标提交和碰撞查询适合处理多个物体。

物理世界和物体状态支持快照保存与恢复，可记录刚体、接触、约束、角色、车辆、布娃娃和软体等状态，用于匹配环境下的回放或回滚；恢复需要匹配的库二进制、世界拓扑和物体身份。调试功能提供碰撞形状、物体与约束线条，以及事件队列和模拟时间等统计。

物理世界可配置重力、时间步、物体和碰撞容量、工作线程、临时内存以及启用的功能；还可查询构建版本、位置精度和物理模块的可用能力。确定性模式需要使用开启对应编译选项的原生库。

## 平台与运行条件

Windows x86-64 和 Linux x86-64 提供 HashLink JIT 与 LLVM AOT 接入；Android arm64 提供 API 24 及以上的 AOT 路径。Linux arm64 和 macOS x86-64/arm64 提供源码构建入口；iOS 未列为当前正式目标。实际能力取决于平台原生模块和构建配置。
